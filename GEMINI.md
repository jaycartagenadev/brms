# Project Rules & Guidelines

## 1. Platform Focus: Desktop and Web Only
- **Target Platforms**: This project strictly targets **Desktop** (Windows, macOS, Linux) and **Web**.
- **Exclude Mobile Platforms**: Do not add mobile-specific code, plugins, configurations, or dependencies (iOS / Android) unless explicitly requested.
- **Desktop & Web UX Standards**:
  - Build responsive layouts optimized for desktop and web viewport sizes (accommodating window resizing, sidebars, multi-column layouts, and wide monitors).
  - Incorporate desktop and web ergonomic expectations, including keyboard shortcuts, tab navigation, mouse hover interactions, and context menus where appropriate.
  - For web builds, ensure routing compatibility, URL handling, and web performance standards.

## 2. Feature Boundaries & Scope Control
- **Strict Scope Adherence**: Do not implement, scaffold, or add features, functionalities, or libraries that are not explicitly permitted or requested by the user.
- **No Speculative Additions**: Avoid unsolicited dependencies, premature abstractions, or unsolicited architectural expansion.
- **Explicit Permission Required**: If an unrequested feature, dependency, or architectural change is deemed helpful or necessary to fulfill a requirement, propose it and wait for user confirmation before implementing.
